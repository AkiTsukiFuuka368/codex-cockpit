# 首次安装与本机用量

安装后直接读取当前电脑的 Codex 用量，不需要加入云空间，也不依赖开发者的配置。
每台新设备生成自己的本地标识，并归入“我 / Me”；已有成员、设备归属和云同步设置不会被重置。

## 找不到记录怎么办？

先自动查找当前用户的数据目录：优先使用启动环境里的 `CODEX_HOME`，否则使用当前用户的 `.codex`。
GUI 启动环境可能没有终端中的环境变量。找不到时，在“设置 → 本机 Codex 数据”选择真实数据目录，
再点击“允许读取并开始统计”。只打开选择器或点取消，不会切换目录。

Mac 上 `.codex` 通常是隐藏文件夹，选择窗口可用 `Command + Shift + .` 显示；
Windows 上可在资源管理器显示隐藏项目。请选择包含 `sessions`、`archived_sessions`、
`state_5.sqlite`、`session_index.jsonl` 或 `auth.json` 的 Codex 目录本身，不要选择整个用户目录。
不接受符号链接目录，避免意外读取另一个位置。不要把 `auth.json` 内容发给别人。

| 界面情况 | 含义 |
| --- | --- |
| 没有找到数据目录 | 没定位到 Codex，不是零用量；手动选择目录 |
| 无法读取目录 | 检查系统读取权限，或重新选择 |
| 目录可读但没有可统计记录 | 先运行一个 Codex 任务，再刷新 |
| 已读到真实的零用量记录 | 正常显示 0，不当成错误 |

## 缓存和隐私

Token 正常但金额没有，不一定是目录或权限问题。新版本自带模型参考价格，
无需旧配置或云同步即可估算；已有自定义／共享价格保留。
缺价或缺少可核对的单次记录仍显示未知，不补成 $0。详见 [金额估算说明](LOCAL-PRICING.md)。

本地配置与汇总缓存放在本 App 的配置目录，不写入 Codex 数据目录。
打开用量页优先使用已知结果，再增量补扫；缺少／不可读的源文件不能把上次已知用量清成零。
选择目录后，官方额度与 Token 统计使用同一目录；官方额度需要有效的 Codex 登录状态，
与历史 Token 记录是否存在是两回事。

选择目录不自动开启云同步，不上传聊天正文、登录凭据或本机路径。
官方额度读取仍在桌面端本地完成，浏览器预览不能证明实机读取成功。

## 已覆盖的自动检查

新用户无旧配置、身份持久化、已有设备归属不变、明确的读取确认、取消不写入、
目录切换不复用旧索引、缺失／空目录／真实零记录区分、本地缓存不依赖云同步、
外来设备不能冒充本地缓存。仍需在 Windows 实机验收选择器、权限、字体及窗口行为。
